# Gruvbox Material Alabaster — единая палитра

Источник правды для всех CLI/TUI-конфигов. Выведена из
`~/.config/helix/themes/alabaster_gruvbox_material_dark_soft.toml`.

## Принцип

**Alabaster-минимализм на палитре gruvbox, прозрачный фон, приглушённые
цвета.** Цель — быстрое чтение и понимание контекста, единообразие во всём
терминале. Цвет тратится только на то, что несёт информацию; всё остальное —
базового цвета.

Голубой (`#7daea3`) допустим **только для ссылок и сносок**. Нигде больше
холодных цветов быть не должно — ни как акцент, ни как «главный» цвет
интерфейса, ни для дат и метаданных.

## 2. Роли в коде

Это главная таблица. Переносить нужно роли, а не hex-коды.

| Что                                              | Цвет           | Слот           |
|--------------------------------------------------|----------------|----------------|
| Переменные, операторы, ключевые слова, скобки     | `#d4be98`      | base05 базовый |
| Главные слова, выделение (или базовый + **bold**) | `#ddc7a1`      | base06         |
| Функции, методы                                   | `#e78a4e`      | base09         |
| Макросы (Rust `!`)                                | `#f0a878`      | orange_light   |
| Строки в кавычках `"..."`, `'...'`                | `#a9b665`      | base0B         |
| Докстринги, многострочные комментарии `/* */`, `"""..."""` | `#d8a657` | base0A     |
| Обычные комментарии `//`, `#`                     | `#7c6f64`      | base03         |
| Вспомогательный код, автовыведенные типы, инлей-хинты | `#7c6f64`  | base03         |
| Классы, типы, конструкторы                        | `#ea6962`      | base08         |
| Константы, числа                                  | `#d3869b`      | base0E         |
| Ссылки, сноски                                    | `#7daea3`      | base0D         |
| Параметры функций                                 | `#bdae93`      | base0F         |
| Пунктуация, разделители                           | `#a89984`      | grey2          |
| Аннотации, декораторы                             | `#89b482`      | base0C         |

**Ключевые слова и операторы намеренно без цвета.** На этом держится
alabaster-минимализм: глаз цепляется только за функции, типы и строки.

| `###`   | `#d8a657` yellow |

## 4. ANSI-раскладка терминала

| # | Роль          | HEX       | # | Роль            | HEX       |
|---|---------------|-----------|---|-----------------|-----------|
| 0 | black         | `#32302f` | 8 | bright black    | `#7c6f64` |
| 1 | red           | `#ea6962` | 9 | bright red      | `#f2827b` |
| 2 | green         | `#a9b665` |10 | bright green    | `#bccc7a` |
| 3 | yellow        | `#d8a657` |11 | bright yellow   | `#e3ba6f` |
| 4 | blue→purple   | `#d3869b` |12 | bright blue     | `#e0a0b2` |
| 5 | magenta       | `#b27085` |13 | bright magenta  | `#c98a9c` |
| 6 | cyan→sage     | `#89b482` |14 | bright cyan     | `#a3c49d` |
| 7 | white         | `#d4be98` |15 | bright white    | `#ddc7a1` |

Слот 0 (`black`) — `bg0`, а не чистый чёрный, чтобы «чёрный» текст не пропадал.

Слот 15 (`bright white`) — `fg1 #ddc7a1`, **а не** `base07 #f9f5d7`. Многие CLI
печатают bright white (`SGR 97` или `bold`+`white`) обычный текст и заголовки;
с `#f9f5d7` он читался как ярко-белый и выбивался из тёплой палитры. `base07`
остаётся только для явных подсветок-вспышек, не для ANSI.

**ANSI-слот 4 остаётся пурпурным, а не голубым.** Голубой разрешён только
для ссылок и сносок, а в слот 4 приложения пишут что попало — директории,
даты, заголовки. Там, где нужен настоящий голубой (ссылка), цвет задаётся
явным `#7daea3`, а не ANSI-кодом.

## 6. Диффы

Фон насыщенный настолько, чтобы added/removed читались периферийным зрением,
но текст поверх оставался читаемым. Знак `+`/`−` — цветной.

| Элемент                     | HEX       |
|-----------------------------|-----------|
| Фон добавленной строки      | `#3a4a30` |
| Фон изменённого слова (+)   | `#4f6640` |
| Знак/текст добавления       | `#a9b665` |
| Фон удалённой строки        | `#4d2e2c` |
| Фон изменённого слова (−)   | `#6b3a36` |
| Знак/текст удаления         | `#ea6962` |
| Приглушённый фон (+)        | `#333a2c` |
| Приглушённый фон (−)        | `#3f2b29` |
| Активная строка (курсор)    | `#504945` |
